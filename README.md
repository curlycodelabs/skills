# CurlyCode skills

Claude Code plugins by [CurlyCode Labs](https://github.com/curlycodelabs).

## Add the marketplace

In Claude Code:

```
/plugin marketplace add curlycodelabs/skills
```

Then install any plugin below with `/plugin install <name>@curlycode`, and just ask Claude for what you need.

## Plugins

| Plugin | What it does | Install |
| --- | --- | --- |
| [storescreenshot](plugins/storescreenshot) | Captures your iOS app in the simulator and turns the screens into App Store screenshots on [StoreScreenshot](https://storescreenshot.app). | `/plugin install storescreenshot@curlycode` |
